About

Before TCU, I spent almost four years as a legal assistant and became a certified Notary Public. That work taught me to be accurate, organized, and careful with details, and I bring the same habits to code. My goal is to become a data analyst at a law firm, where much of the work still lives in spreadsheets and documents that could be faster and easier to use.

This semester I learned how the web actually works. I started with HTML and CSS, then used JavaScript to make pages respond to people: saving their data, filtering lists, and loading information from files. I also learned to work like a developer, with Git for version control, GitHub Pages for deployment, and AI tools as a study partner to explain code I didn't understand yet. The biggest change is that code no longer looks like gibberish to me. I can read it, find where something broke, and fix it.
